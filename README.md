# Crop-Recommendation-System-

Simple demo files for a Crop Recommendation System prototype.

## Contents

- agri-ai.html — frontend demo (open in a browser)
- agri-ai.css — styles for the demo
- Hello.js — example JavaScript file included in the project
- hello.py — example Python script (run with Python 3)

## Quickstart

1. To view the web demo, open `agri-ai.html` in your browser.
2. To run the Python example (if needed):

```bash
python hello.py
```
